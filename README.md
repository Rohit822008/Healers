# Healers — Hospital Visitor Management System

A responsive front-end web portal built with pure HTML5 and CSS3 to structure hospital visitor registration, ward visiting schedules, digital entry passes, active visitor tracking, and safety protocols.

**Live Demo:** https://rohit822008.github.io/Healers/

## Project Modules
- **Home (`index.html`):** Overview of the hospital visitor workflow and essential entry guidelines.
- **Register Visitor (`register.html`):** Visitor identification and admitted patient association form.
- **Visiting Time (`visiting-time.html`):** Department-wise visiting schedules and visitor limits for General Wards, ICU, and Private Rooms.
- **Visitor Pass (`pass.html`):** Digital entry pass search, verification badge, and QR ID display.
- **Active Visitors (`active-visitors.html`):** Real-time ward occupancy counters and visitor exit logging.
- **Health & Safety (`protocols.html`):** Mandatory hygiene, infection control, and ward conduct guidelines.

## Tech Stack
- **HTML5** (Semantic multi-page structure)
- **CSS3** (Flexbox, CSS Grid, sticky navigation, and responsive card layout)
